Handles real-time data synchronization between multiple remote servers for distributed teams and applications.

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/TideRift.git`
2. `cd TideRift`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure TideRift, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
